# Icônes PWA

Placer ici (avant le build prod) :

- `icon-192.png` - 192×192, fond plein
- `icon-512.png` - 512×512, fond plein
- `icon-maskable-512.png` - 512×512, safe zone 80% (cf. <https://maskable.app>)

Couleur de fond : `#1A1A1A` (eldir-ink). Logo : flamme orange `#D97757`.

Pendant le dev, vite-plugin-pwa fonctionne sans ces fichiers (warnings ignorables).
